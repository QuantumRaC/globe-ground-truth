# groundtruth-site

**Ground Truth: GLOBE — an educational brief on NASA's GLOBE Observer programme, with Florida
as the worked example.**

🔗 **Live:** <https://quantumrac.github.io/globe-ground-truth/>

Built for the NASA & Environmental Data track at CityCamp Gainesville Hack Day,
20 September 2026.

---

Satellites and climate models are very good guesses, and a guess has to be checked
against something real. That check is called ground truth, and someone has to be
standing there to make it. This page explains how GLOBE turns ordinary people into
that reference, shows how close the models actually get, and maps where nobody has
looked yet.

## What's on it

An interactive county map of Florida with two views, cycling on its own until you
touch it:

- **Intensity** — counties shaded by how many observations they hold, in quantile bins
- **Observations** — each reading coloured by what it actually recorded; rest the
  pointer on a dot for half a second to see the record as the participant filed it

Four GLOBE protocols, ordered by how well a satellite can already see them:

| Protocol | Records | Distinct observers | Counties reached | ERA5 counterpart |
|---|---:|---:|---:|---|
| Sky conditions | 11,273 | **860** | 46 / 67 | `cloud_cover`, same hour |
| Tree heights | 1,813 | **314** | 41 / 67 | none |
| Land cover | 808 | **148** | 35 / 67 | soil moisture, only by analogy |
| Mosquito habitat | 634 | **73** | 23 / 67 | none |

Then three sections: why ground truth needs a person, how close ERA5 actually gets,
what no instrument can record at all, and where the blanks are.

## How it's built

A single `index.html` — no build step, no framework, no API calls at page load. Every
number on the page is read from `data/*.json` rather than written into the copy, so
the prose cannot drift from the data. Leaflet for the map, Chart.js for the one chart,
everything else inline.

```
index.html        the page
data/*.json       counties, points, observer counts, the ERA5 comparison
```

Serve it locally with:

```bash
python -m http.server 8765
```

## Where the data comes from

`data/` is generated by
[**globe-ground-truth-pipeline**](https://github.com/QuantumRaC/globe-ground-truth-pipeline), which
downloads the GLOBE records, matches each to ERA5, and aggregates to counties:

```bash
python groundtruth.py all --region florida
```

The pipeline is region-agnostic — change one bounding box and this page can be rebuilt
for anywhere.
